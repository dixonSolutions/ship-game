# Ship Game maps

| File | Role |
| --- | --- |
| `ocean1.map` / `ocean1.bsp` | Free CC0 ocean arena source + compile (minimal brushes). Needs a proper WAD/texture bake — currently missing world textures (checkerboard / black sky under DarkPlaces). |
| `ocean1_start_stub.bsp` | Old untextured `start.bsp` copy kept for reference. |
| `start.bsp` (+ `.lit`) | Extracted from LibreQuake lite for a textured hub while debugging QuakeC / GDR. Regenerated by `scripts/dp-extract-lq-maps.sh`. |
| `lq_e0m1.bsp` | Optional LibreQuake episode map extract for playtests. |

## Launch

```bash
./scripts/qc-build.sh
./scripts/dp-fetch-librequake.sh
# Flatpak engine + local basedir:
flatpak run --filesystem="$PWD/darkplaces" --command=/app/bin/darkplaces-sdl \
  com.dixonsolutions.ShipGame -basedir "$PWD/darkplaces" -game shipgame +map start +r_fullbright 1
```

Launcher default remains `+map ocean1` once the arena has embedded textures.
