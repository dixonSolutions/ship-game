# Future roadmap

## Near term

- Richer sail aerodynamics and wake foam particles
- Cannon VFX (recoil, smoke, impacts) and damage decals
- Crew animations + in-world dialogue bubbles wired to Bedrock/Polly
- Touch virtual controls and improved gamepad aiming
- Graphics quality presets (ocean resolution, shadows, fog)

## Mid term

- Multi-mast ships, boarding, faction reputation
- Dynamic campaign encounters and tsunami set-pieces
- Spatial audio buses (wind relative to camera, cannon doppler)
- Playwright smoke tests for boot + pause + API mock

## Later

- Multiplayer glimpses / shared seas
- Asset pipeline for credited meshes and recorded SFX
- Accessibility: colorblind palettes, reduced motion, remappable inputs
- Progressive Web App install + offline mock voyage
